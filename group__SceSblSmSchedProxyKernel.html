◆ SceSmStatus

enum SceSmStatus

Secure-module scheduler lifecycle states.

FW 3.60 SceSblAuthMgr and SceSblSsSmComm clear bit 0x8 before comparing a callback status with SCE_SM_STATUS_RUNNING. The purpose of that bit is unknown.

A request enters SCE_SM_STATUS_READY when created or after suspension completes. The normal scheduling path is SCE_SM_STATUS_READY -> SCE_SM_STATUS_START_RESUME_REQUESTED -> SCE_SM_STATUS_RUNNING. Preemption follows SCE_SM_STATUS_RUNNING -> SCE_SM_STATUS_SUSPEND_REQUESTED -> SCE_SM_STATUS_SUSPENDING -> SCE_SM_STATUS_READY. A request that finishes normally enters SCE_SM_STATUS_STOPPED. An explicit force-stop or scheduler shutdown puts it in SCE_SM_STATUS_FORCE_STOPPED.

◆ ksceSblSmSchedProxyForceStop()

int ksceSblSmSchedProxyForceStop ( SceSmSchedRequestId  req_id)

Forcibly stop a secure-module scheduler request through SMC 0x130.

SCE_SM_STATUS_READY and SCE_SM_STATUS_SUSPENDING requests are first moved to SCE_SM_STATUS_READY and then enter SCE_SM_STATUS_FORCE_STOPPED. SCE_SM_STATUS_RUNNING and SCE_SM_STATUS_START_RESUME_REQUESTED requests issue secure control command 0x501 and transition through internal states 0xC and 0x9 before reaching SCE_SM_STATUS_FORCE_STOPPED.

Parameters
req_id- Scheduler request ID.
Returns
0 on success, SCE_SM_SCHED_PROXY_ERROR_REQUEST_ALREADY_STOPPED when the request is not in a stoppable state, or another negative scheduler validation error.

◆ ksceSblSmSchedProxyExecuteSKCommand()

int ksceSblSmSchedProxyExecuteSKCommand ( SceUInt32  command_index,
SceUInt32  unused1,
SceUInt32  unused2,
SceUInt32  unused3 
)

Execute a secure scheduler control command selected by index through SMC 0x13C.

FW 3.60 accepts command indices 0 through 4 and writes control values 0xB01 through 0xF01 respectively to the secure scheduler control register. The three remaining arguments are forwarded by the non-secure proxy but ignored by the secure handler.

SceSdif uses command index 3 while resetting the eMMC host controller. SceSblSsMgr uses command index 4 at the end of the 0x20F-through-0x200 system-suspend event sequence. These call sites do not establish the exact hardware purposes of either command.

Parameters
command_index- Secure-monitor command index.
unused1- Ignored on FW 3.60; set to 0.
unused2- Ignored on FW 3.60; set to 0.
unused3- Ignored on FW 3.60; set to 0.
Returns
0 on success, SCE_SM_SCHED_PROXY_ERROR_INVALID_ARGUMENT for an index greater than 4, or SCE_SM_SCHED_PROXY_ERROR_NOT_INITIALIZED.

◆ ksceSblSmSchedProxyInvoke()

int ksceSblSmSchedProxyInvoke ( SceBool  priority,
SceUIntPtr  pa_ranges_paddr,
SceSize  pa_range_count,
const SceSmInvokeDataBlockInput *  invoke_input,
const SceSblSmCommContext130 *  context,
SceSmSchedRequestId *  request_id 
)

Start a secure-module scheduler request through SMC 0x12D.

Parameters
priority- Boolean priority: 0 for high priority, 1 for low priority.
pa_ranges_paddr- Physical address of an array of SceKernelPARange entries. It is required when (context->self_type & 0xF000) == 0 and must be 0 when that value is 0x1000.
pa_range_count- Number of entries in the physical-address range array. It must be 0 when (context->self_type & 0xF000) == 0x1000.
invoke_input- Optional four-word startup data, copied unchanged. The secure module defines their meaning; the scheduler does not interpret them. NULL passes four zero words.
context- Launch context; must be non-NULL. FW 3.60 reads only self_type, media_type, and the program authority ID and capability from spawner_self_auth_info.
request_id- Receives the scheduler request ID; must be non-NULL.

Values of context->self_type & 0xF000 other than 0 or 0x1000 are rejected. A request ID is assigned before the shared-buffer and secure-monitor work; callers may therefore receive an assigned ID even when a later step fails. The proxy can track at most 64 concurrent request records.

Returns
Secure-monitor result or a negative scheduler/kernel error.
