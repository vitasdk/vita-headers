◆ _sceSblGcAuthMgrGetMediaIdType01()

int _sceSblGcAuthMgrGetMediaIdType01 ( SceMediaIdType01 *  media_id,
const SceSblGcAuthMgrGetMediaIdType01Opt *  opt 
)

Get the type-01 game-card media ID.

Both pointers must be non-NULL. FW 3.60 always obtains the complete 0x20-byte value internally and copies its first opt->media_id_size bytes.

Parameters
[out]media_id- Media-ID output.
[in]opt- Required output size.
Returns
0 on success; 0x808A0700 for an invalid output or secure-command failure; 0x808A0701 for a semaphore failure; 0x808A0703 when no validated game-card context exists; or another negative copy error.

◆ _sceSblGcAuthMgrPcactActivation()

int _sceSblGcAuthMgrPcactActivation ( const ScePcactActivationData *  activation_data,
SceSize  activation_data_size 
)

Validate and install PC activation data.

The envelope must match the currently saved challenge state. On success the 0x1040-byte payload is passed to NPDRM before this function returns. The input buffer is not used after this function returns. After any activation attempt with the correct size, FW 3.60 clears its saved challenge state even when envelope verification or NPDRM installation fails.

Parameters
[in]activation_data- Required complete activation object.
[in]activation_data_size- Must equal 0x1090.
Returns
0 on success, or a negative validation, cryptographic, copy, or NPDRM error.

◆ _sceSblGcAuthMgrPcactGetChallenge()

int _sceSblGcAuthMgrPcactGetChallenge ( SceUInt32  mode,
const SceUInt8 *  e_password,
ScePcactChallenge *  challenge,
const ScePcactGetChallengeOpt *  opt 
)

Create a PC activation challenge.

All pointers must be non-NULL. The function uses a complete 0x20-byte password block and generates a complete challenge internally; opt only controls how many bytes are copied from or to the caller's buffers.

Parameters
[in]mode- One of ScePcactMode.
[in]e_password- Required 0x20-byte password block.
[out]challenge- Challenge output.
[in]opt- Required copy sizes.
Returns
0 on success; 0x808A0380 for an invalid pointer or mode; 0x808A0383 when mode 1 finds existing activation data; 0x808A0384 when mode 0 is used before challenge expiration; or another negative RTC, cryptographic, or copy error.

◆ _sceSblGcAuthMgrPkgVry()

int _sceSblGcAuthMgrPkgVry ( const SceUInt8 *  hash,
const SceUInt8 *  signature,
const SceSblGcAuthMgrPkgVryInfo *  info 
)

Verify a package ECDSA-160 signature.

The hash and signature pointers must be non-NULL. FW 3.60 uses a complete 0x14-byte hash and 0x28-byte signature. Do not use smaller copy sizes for verification: they leave the remaining bytes unspecified.

Parameters
[in]hash- SHA-1 digest.
[in]signature- Raw ECDSA-160 signature.
[in]info- Required copy sizes.
Returns
0 when valid; 0x808A0008 for a semaphore failure; 0x808A000C for invalid input or a rejected signature; or another negative copy error.
