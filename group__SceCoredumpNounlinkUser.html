int sceCoredumpWriteUserData ( const void *  data,
SceSize  size 
)

Appends data to the current coredump's user-data section.

This function is intended to be called from a SceCoredumpHandler. All calls made by one handler share a 0x4000-byte buffer on FW 3.60. If the requested data does not fit, the call succeeds, appending only as many bytes as fit.

Parameters
[in]dataData to append.
[in]sizeNumber of bytes requested.
Returns
The number of bytes appended, which can be less than size when the buffer is full, or a negative error code. This uses the same byte-count or error convention as SceSSize, although the declared return type is int.
Return values
0x800A0000The user buffer is inaccessible.
0x800A0003No user-data capture is active.
