◆ _sceKernelGetRandomNumber()

int _sceKernelGetRandomNumber ( void *  dst,
SceSize  length,
const SceKernelGetRandomNumberParam *  param 
)

Generate up to 0x40 bytes using SceSblRng's pseudorandom generator.

The function first generates length bytes, then copies SceKernelGetRandomNumberParam::dst_size bytes to dst. If this count is larger than length, the extra bytes are zero. The public sceKernelGetRandomNumber wrapper sets both sizes to the same value.

Parameters
[out]dst- Required destination buffer.
[in]length- Number of random bytes to generate; must be at most 0x40.
[in]param- Required eight-byte input parameter structure.
Returns
0 on success, < 0 on error.
