◆ sceFiosKernelOverlayGetList02()

int sceFiosKernelOverlayGetList02 ( SceUID  pid,
SceUInt8  min_order,
SceUInt8  max_order,
const sceFiosKernelOverlayGetList02_opt *  opt 
)

Gets the IDs of overlays whose order is from min_order through max_order, inclusive.

opt must be non-NULL. When opt->out_ids is non-NULL, opt->max_ids must not exceed 128 on FW 3.60. opt->actual_ids may be NULL; when supplied it receives the total number of matching overlays, including those beyond opt->max_ids. The reserved fields are ignored on FW 3.60.

Parameters
[in]pid- Process whose overlays are enumerated.
[in]min_order- Minimum overlay order to include.
[in]max_order- Maximum overlay order to include.
[in]opt- Enumeration options and output pointers.
Returns
0 on success, or an error code.

int sceFiosKernelOverlayGetRecommendedScheduler02 ( int  scheduler_count,
const char *  partially_resolved_path,
const sceFiosKernelOverlayGetRecommendedScheduler02_opt *  opt

Gets the recommended scheduler index for a partially resolved path.

opt must be non-NULL. FW 3.60 copies all eight bytes from user memory but does not use their contents. partially_resolved_path may be NULL; a non-NULL path must terminate within 0x400 bytes.

Parameters
[in]scheduler_count- Number of available schedulers.
[in]partially_resolved_path- Optional partially resolved path.
[in]opt- Non-NULL pointer to an 8-byte option block.
Returns
1 for a host[0-9]: path when scheduler_count is greater than 1, otherwise 0, or a negative error code when a user-memory copy fails.

Replaces an overlay in a process's table.

Validates and copies new_value before returning. Keeps the process and overlay IDs, recalculates both path lengths, and moves the entry to its new position in the table if its order changes. new_value must remain valid until this function returns; it is not used afterwards.

Parameters

[in]id- Overlay identifier.
[in]new_value- Replacement overlay configuration.
Returns
0 on success, or a negative error code.

int sceFiosKernelOverlayResolveSync02 ( SceUID  pid,

const char *  in_path,

Resolves a path synchronously through a process's overlays.

resolve_for_write must be 0 for a read or 1 for a write. opt must be non-NULL. Its max_path field controls path validation and resolution, while out_path_buffer_size independently controls the final copy to user memory. The reserved fields are ignored on FW 3.60.

Parameters
[in]pid- Process whose overlays are used.
[in]resolve_for_write- Must be 0 for read resolution or 1 for write resolution.
[in]in_path- Path to resolve.
[in]opt- Resolution options and output buffer.
Returns
0 on success, or a negative error code.

◆ sceFiosKernelOverlayResolveWithRangeSync02()

int sceFiosKernelOverlayResolveWithRangeSync02 ( SceUID  pid,
int  resolve_for_write,
const char *  in_path,
const sceFiosKernelOverlayResolveWithRangeSync02_opt *  opt 
)

Resolves a path through overlays whose order is between min_order and max_order, inclusive.

opt must be non-NULL. min_order and max_order are unsigned, and min_order must not exceed max_order. max_path controls path validation and resolution; out_path_buffer_size independently controls the final copy to user memory. The reserved fields are ignored on FW 3.60. If application overlays are disabled for the current thread, the supplied min_order is replaced with 0x80.

Parameters
[in]pid- Process whose overlays are used.
[in]resolve_for_write- Must be 0 for read resolution or 1 for write resolution.
[in]in_path- Path to resolve.
[in]opt- Resolution options and output buffer.
Returns
0 on success, or an error code.

◆ sceFiosKernelOverlayThreadIsDisabled02()

int sceFiosKernelOverlayThreadIsDisabled02 ( void  )

Returns whether application overlays are disabled for the current thread.

A nonzero state skips orders 0x00 through 0x7F. Privileged overlays with orders 0x80 through 0xFF remain active.

Returns
0 or 1.

◆ sceFiosKernelOverlayThreadSetDisabled02()

int sceFiosKernelOverlayThreadSetDisabled02 ( int  disabled)

Enables or disables application overlays for the current thread.

Any nonzero value skips orders 0x00 through 0x7F until this function is called with zero or the thread exits. Privileged orders 0x80 through 0xFF remain active.

Parameters
[in]disabled- Zero to enable application overlays, or any nonzero value to disable them.
Returns
0 on success, or -1 if the thread-local state is unavailable.
