◆ sceSharedFbCreate()

SceUID sceSharedFbCreate ( int  index,
const SceSharedFbCreate *  create_param 
)

Create a shared-framebuffer object.

FW 3.60 supports two objects at a time. PAF creates index 1. The calling process must be a system program.

Parameters
[in]indexNon-negative shared-framebuffer index.
[in]create_paramRequired 0x18-byte SceSharedFbCreate structure.
Returns
The shared-framebuffer ID on success, or a negative error code.

◆ sceSharedFbUpdateProcess()

int sceSharedFbUpdateProcess ( void  )

Perform one process handoff after sceSharedFbUpdateProcessBegin.

Call this function exactly the number of times specified by the update_count output of sceSharedFbUpdateProcessBegin, then call sceSharedFbUpdateProcessEnd.

Returns
1 when the selected process is marked for rendering, 0 otherwise, or a negative error code.

◆ sceSharedFbUpdateProcessBegin()

int sceSharedFbUpdateProcessBegin ( SceUID  shared_fb_id,
const SceSharedFbRenderInfo *  render_info,
SceUInt32 *  update_count 
)

Begin a shared-framebuffer update.

Both pointers must be non-NULL on FW 3.60. The calling process must be a system program and shared_fb_id must identify one of the two created shared framebuffers.

Parameters
[in]shared_fb_idShared-framebuffer ID.
[in]render_infoRendering information copied into the shared framebuffer.
[out]update_countReceives the 32-bit number of required sceSharedFbUpdateProcess calls.
Returns
0 on success, or a negative error code.

◆ sceSharedFbUpdateProcessEnd()

int sceSharedFbUpdateProcessEnd ( void  )

Complete a process handoff sequence begun by sceSharedFbUpdateProcessBegin.

This function takes no arguments and must be called after the corresponding update-process loop.

Returns
0 on success, or a negative error code.
