◆ ksceMsifDisableSlowCardMode()

int ksceMsifDisableSlowCardMode ( void  )

Disable slow-card mode.

Slow-card mode does not change the MSIF controller clock. It adds minimum completion delays after successful sector reads and writes, including periodic 350 or 400 ms pauses.

Returns
Always 0.

◆ ksceMsifReadSector()

int ksceMsifReadSector ( SceUInt32  sector,
void *  buffer,
SceUInt32  sector_count 
)

Read sectors from the Memory Stick medium.

Parameters
[in]sector- First logical sector to read.
[out]buffer- Destination for sector_count * SCE_MSIF_SECTOR_SIZE bytes. Must be aligned to 4 bytes.
[in]sector_count- Number of sectors to read. Must not be 0.
Returns
0 on success, a negative SceMsifErrorCode value, a mapped medium error, or a fast-mutex error.
