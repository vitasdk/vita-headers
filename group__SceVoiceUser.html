◆ SceVoiceEventCallback

typedef void(* SceVoiceEventCallback) (const SceVoiceEvent *event)

Voice event callback.

Callbacks run one at a time on SceVoice's private event thread. The event is stored on that thread's stack and is valid only until the callback returns. Other SceVoice functions may be called from the callback, but sceVoiceEnd must not be called because it waits for the event thread.

Parameters
[in]event- Event record valid for the duration of the callback.

◆ sceVoiceStart()

int sceVoiceStart ( const SceVoiceStartParam *  param)

Attach the Voice instance to its working-memory block and start processing.

FW 3.60 uses 0x28000 bytes as private memory followed by 0x18000 bytes as shared memory. It does not validate the memory-block size, so the supplied block must contain at least SCE_VOICE_WORKING_MEMORY_SIZE bytes. SceVoice does not take ownership of the block; it must remain allocated until sceVoiceStop or sceVoiceEnd returns.

Calling this function for an already started instance succeeds without changing the current working-memory block. A non-NULL param is still required in that case.

Parameters
[in]param- Start parameters.
Returns
0 on success, or a negative SceVoiceErrorCode value.

◆ sceVoiceStop()

int sceVoiceStop ( void  )

Stop Voice processing and detach the working-memory block.

Port configurations and connections are retained, but their audio-processing resources and buffered data are discarded. A later sceVoiceStart recreates the processing resources. SceVoice does not free the caller-owned memory block.

Calling this function when Voice is initialized but already stopped succeeds.

Returns
0 on success, or a negative SceVoiceErrorCode value.

◆ sceVoiceCheckTopology()

int sceVoiceCheckTopology ( void  )

Check whether the current port connections are valid.

FW 3.60 checks that every created port has at least one connection. It also requires each adjacent pair of OUT_VOICE ports in the internal output list to use the same bitrate, the same per-port mute state (zero or nonzero), and exactly equal volume values. When both IN_DEVICE and IN_PCMAUDIO ports exist, it also rejects an OUT_VOICE port connected from IN_PCMAUDIO while that output's encoder has not been assigned, as occurs before Voice is started.

Returns
0 when the port connections are valid, or a negative SceVoiceErrorCode value.

◆ sceVoiceCreatePort()

int sceVoiceCreatePort ( SceVoicePortId *  port_id,
const SceVoicePortParam *  param 
)

Create a Voice port.

PCMAUDIO ports accept signed 16-bit little-endian PCM at 16000 Hz. Their effective byte capacity is rounded down to a multiple of 512 and must be from 1024 through 64512 bytes. VOICE ports use one of SceVoiceBitRate. FW 3.60 truncates the rounded PCM capacity to 16 bits before validating it; callers should pass a value in the documented range rather than relying on that wraparound.

For application-fed input ports, SceVoicePortParam::threshold must be shorter than the duration represented by the port's buffer. The type-specific union member must be zero for a device port.

Parameters
[out]port_id- Receives a port identifier from 0 through 63.
[in]param- Port configuration.

FW 3.60 writes 0xFF to port_id before validation. If immediate startup of the port's audio processing fails, the function returns that error after creating the port and replacing 0xFF with its valid port ID.

Returns
0 on success, or a negative SceVoiceErrorCode value.

◆ sceVoiceUpdatePort()

int sceVoiceUpdatePort ( SceVoicePortId  port_id,
const SceVoicePortParam *  param 
)

Update an existing port's configuration.

The port type cannot be changed. Changing an encoded bitrate creates a new encoder or decoder for the port and discards its buffered data.

Do not change a PCMAUDIO port's data.buffer_size on FW 3.60. The function never reallocates or reinitializes the PCM ring buffers. The first update stores the new requested size but keeps the old size used for resource accounting. A later update recalculates the accounting size from that stored value. Deleting the port then releases resources according to the changed accounting size, not the capacity originally allocated. This function does not check SceVoicePortParam::threshold again against the queue duration.
