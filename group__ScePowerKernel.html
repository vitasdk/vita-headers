◆ ScePowerBatteryFakeStatus

struct ScePowerBatteryFakeStatus

Simulated battery state used by kscePowerSetBatteryFakeStatus.

When discharge_time is nonzero, FW 3.60 linearly decreases the reported remaining capacity from remaining_capacity to zero over that many microseconds. A zero duration keeps the simulated capacity constant.

Data Fields
SceSize size Must be sizeof(ScePowerBatteryFakeStatus).
SceUInt32 remaining_capacity Initial remaining capacity in mAh. See kscePowerSetBatteryFakeStatus.
SceUInt32 full_capacity Full capacity in mAh; 0 is treated as 2000.
SceUInt32 discharge_time Simulated discharge duration in microseconds, or zero to keep the capacity constant.

◆ kscePowerSetIdleCallback()

int kscePowerSetIdleCallback ( SceUInt32  index,
int  flags,
SceUInt64  duration,
ScePowerIdleCallback  callback,
void *  user_data 
)

Configure one of the eight global idle callbacks.

FW 3.60 stores only the low 16 bits of flags. Bit 0x200 makes the slot's activity timestamp reset only when its corresponding explicit tick bit is supplied. Bit 0x400 makes resets conditional on the current display/input policy. The purpose of other flag bits is unknown. The callback is called once after duration expires and again with an idle time of zero if later activity resets the expired slot.

Parameters
[in]indexSlot from 0 through 7. A tick for this slot uses 1U << index with kscePowerTick.
[in]flagsIdle policy flags.
[in]durationExpiration interval in microseconds, or zero to use the global fallback interval.
[in]callbackCallback to install, or NULL to clear the slot.
[in]user_dataValue passed to callback.
Returns
0 on success, SCE_POWER_ERROR_INVALID_VALUE for an invalid index, or SCE_POWER_ERROR_ALREADY_REGISTERED when replacing a non-NULL callback with another non-NULL callback.
