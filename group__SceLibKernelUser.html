SceKernelCallFrame *  call_frame_buffer,
SceSize  num_bytes_buffer,
SceUInt32 *  num_frames,
SceInt32  mode 
)

Gets a thread backtrace.

Parameters
[in]thread_idThread ID, or SCE_KERNEL_BACKTRACE_CONTEXT_CURRENT.
[out]call_frame_bufferBuffer that receives the call frames, or NULL when num_bytes_buffer is 0.
[in]num_bytes_bufferSize of the call-frame buffer in bytes. A non-NULL buffer must hold at least one frame.
[out]num_framesOptional pointer that receives the number of frames written to the output buffer.
[in]modeBitwise OR of SceKernelBacktraceMode values.
Returns
With SCE_KERNEL_BACKTRACE_MODE_DONT_EXCEED, 0 on success. Otherwise, the complete call-stack depth on success, even when the output buffer is too small to contain every frame. Returns < 0 on error.

◆ sceKernelWaitEvent()

SceInt32 sceKernelWaitEvent ( SceUID  event_id,
SceUInt32  wait_pattern,
SceUInt32 *  result_pattern,
SceUInt64 *  user_data,
SceUInt32 *  timeout 
)

Waits until any requested event bit is present.

When the event has the auto-clear attribute, the matched bits are removed after a successful wait. This function does not dispatch callbacks while blocked.

Parameters
[in]event_idEvent identifier.
[in]wait_patternPattern of bits to wait for.
[out]result_patternOptional pointer that receives the matched bits.
[out]user_dataOptional pointer that receives the event's user data.
[in,out]timeoutOptional timeout in microseconds. If the call blocks, it receives the remaining duration; it receives 0 when the timeout expires. It is left unchanged when the wait is satisfied immediately.
Returns
0 on success, or < 0 on error.
