SceSize  size 
)

Allocates a user memblock without mapping it.

FW 3.60 accepts only sizes aligned to 1 MiB and copies at most 31 bytes of name. This function is available only while user remapping is enabled.

Parameters
[in]name- Memory-block name.
[in]size- Allocation size, aligned to 1 MiB.
Returns
The memblock UID in the calling process on success, < 0 on error.

◆ sceKernelCheckModelCapability()

int sceKernelCheckModelCapability ( int  capability_index)

Tests a hardware-model capability whose purpose is unknown.

FW 3.60 accepts only indices 7 and 10. Index 10 identifies the Teleport-client model: TeleportClient requires it, while TeleportServer rejects operation when it is present. The purpose of index 7 is unknown; no caller in the FW 3.60 dumps uses it.

Parameters
[in]capability_indexCapability bit index.
Returns
1 if the capability is present, 0 if it is absent, SCE_KERNEL_ERROR_INVALID_ARGUMENT if the index is unsupported.
