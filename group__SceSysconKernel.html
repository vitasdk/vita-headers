◆ ksceSysconBatteryExecBLCommand()

int ksceSysconBatteryExecBLCommand ( SceUInt16  command_context)

Execute the current battery-bootloader command context.

FW 3.60 uses Syscon command 0x09B3. On Baryon versions through 0x00070503 it uses the legacy command 0x08B3. SceSblUpdateMgr numbers script records starting at 1 and uses each record's number as the command context.

Parameters
[in]command_contextBattery-bootloader command context.
Returns
0 on success, or a negative Syscon error.

◆ ksceSysconBatteryReadBLCommand()

int ksceSysconBatteryReadBLCommand ( SceUInt16  command_context,
SceUInt8  request0,
SceUInt8  request1,
void *  dst,
SceUInt8  size 
)

Read data from a battery-bootloader command response.

FW 3.60 uses Syscon command 0x09B4, or legacy command 0x08B4 on Baryon versions through 0x00070503. The two request bytes are transmitted independently and unmodified; their individual purposes are unknown.

Parameters
[in]command_contextBattery-bootloader command context.
[in]request0First raw request byte.
[in]request1Second raw request byte.
[out]dstRequired buffer that receives size bytes.
[in]sizeNumber of bytes to read, from 1 through SCE_SYSCON_BATTERY_BL_MAX_TRANSFER_SIZE.
Returns
0 on success, 0x80250001 for an invalid size, or a negative Syscon error.

◆ ksceSysconBatterySWReset()

int ksceSysconBatterySWReset ( void  )

Request a battery-controller software reset.

FW 3.60 uses Syscon command 0x0989. Baryon versions through 0x00070503 do not support this operation and return 0x8025023F without sending a command.

Returns
0 on success, or a negative Syscon error.

Write one chunk of battery-bootloader command data.

FW 3.60 uses Syscon command 0x09B2, or legacy command 0x08B2 on Baryon versions through 0x00070503. SceSblUpdateMgr uses offset as the byte offset of this chunk within the current script record.

Parameters
[in]command_contextBattery-bootloader command context.
[in]offsetByte offset of the chunk within the command data.
[in]srcRequired source buffer.
[in]sizeNumber of bytes to write, from 1 through SCE_SYSCON_BATTERY_BL_MAX_TRANSFER_SIZE.
Returns
0 on success, 0x80250001 for an invalid size, or a negative Syscon error.

◆ ksceSysconGetMultiCnInfo()

int ksceSysconGetMultiCnInfo ( SceUInt32 *  info)

Get the cached multi-connector information, with the mappings below.

Bits 8 through 15 contain the connector code. On hardware versions below 0x00400000, FW 3.60 maps the raw codes 0x60, 0x51, 0x65, and 0x55 to 0x00, 0x02, 0x04, and 0x05 respectively, and maps every other raw code to 0xFF. A genuine PSTV receives code 0x00 regardless of the cached value.

SceUsbServ treats codes 0x00 and 0x04 as permitting USB device mode on the older multi-connector hardware. SceHpremote identifies code 0x03 as an audio-output dock.

Parameters
[out]infoOptional output for the 32-bit information value after mapping.
Returns
Always 0 on FW 3.60.
