Get a PSM RIF key set and license information.

Parameters
[in]license- Required PSM RIF data (0x400 bytes)
[out]keydata- Required ScePsmDrmKeySet output
[out]version_flag- Optional activation version flag output
[out]lic_start_time- Optional license start time output
[out]lic_exp_time- Optional license expiration time output

The returned start time is the later of the activation and license start times. The returned expiration time is the earlier of their expiration times.

Returns
0 on success, < 0 on error.
