◆ sceSblUtMgrGetRemainingValidityTime()

int sceSblUtMgrGetRemainingValidityTime ( int *  remaining_seconds)

Get the remaining validity time for the initialized Utoken.

Only system programs may call this function.

Parameters
[out]remaining_seconds- Receives -1 when no validity deadline is configured or the deadline is 0xFFFFFFFF, 0 when the deadline has passed, or the number of seconds until the deadline otherwise.
Returns
SCE_OK on success, 0x800F1A26 if no Utoken has been initialized, or another negative error code.

Copy the Utoken name.

Only system programs may call this function. The Utoken must be initialized. No terminator is added when fewer than 0x18 bytes are copied.

Parameters
[out]name- Destination buffer.
[in]size- Destination size. At most 0x18 bytes are copied.
Returns
SCE_OK on success, < 0 on error.

◆ sceSblUtMgrReadUtoken()

int sceSblUtMgrReadUtoken ( SceUtoken *  utoken,
SceSize  size 
)

Read and verify the stored encrypted Utoken.

Only system programs may call this function.

The returned contents remain encrypted; FW 3.60 uses secure-module command 1 only to verify them before copying them to user memory.

Parameters
[out]utoken- Receives the encrypted Utoken.
[in]size- Must be at least 0x800; exactly 0x800 bytes are written.
Returns
SCE_OK on success, < 0 on error.

◆ sceSblUtMgrResetUtokenFile()

int sceSblUtMgrResetUtokenFile ( void  )

Overwrite and remove the stored Utoken file.

Only system programs may call this function.

Already parsed Utoken flags remain cached on FW 3.60 until the module is reinitialized.

Returns
SCE_OK on success, < 0 on error.
