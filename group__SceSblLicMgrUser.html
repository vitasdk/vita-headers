◆ sceSblLicMgrActivateDevkit()

int sceSblLicMgrActivateDevkit ( const char *  afv_path)

Activate a development or testing kit from an AFV file.

This operation is restricted to system programs. FW 3.60 copies at most 255 path bytes and accepts paths under host0:, ux0:/data/activate/, and ur0:/temp/activation. A successful installation does not recalculate the cached license state.

Parameters
[in]afv_path- NUL-terminated activation-file path.
Returns
SCE_OK on success, or a negative error code.

◆ sceSblLicMgrClearActivationData()

int sceSblLicMgrClearActivationData ( void  )

Clear activation data in NVS and in tm0:activate/.

FW 3.60 overwrites the stored data with 0xFF bytes rather than removing the two activation files. It does not recalculate the cached license state. This operation is restricted to system programs.

Returns
SCE_OK on success, or a negative error code.

SceBool  read_from_nvs

Get the cached expiration time or the remaining activation time.

This operation is restricted to system programs. When read_from_nvs is zero, FW 3.60 writes the cached absolute expiration time to expire_date. When it is nonzero, FW 3.60 reads and verifies NVS and writes the number of seconds remaining to expire_date.

Parameters
[out]expire_date- Receives the expiration result described above.
[in]read_from_nvs- Nonzero to refresh from NVS; zero uses the cache.
Returns
SCE_OK on success, or a negative error code.

◆ sceSblLicMgrGetUsageTimeLimit()

int sceSblLicMgrGetUsageTimeLimit ( SceUInt32 *  time_limit)

Get the kit's remaining activation time in seconds.

On success, a zero value in time_limit means the kit has expired. This operation is restricted to system programs. When any QAF flag is set, FW 3.60 writes the bitwise complement of the current secure Unix time to time_limit as an effectively unrestricted value instead of the normal expiration interval.

Parameters
[out]time_limit- Receives the remaining number of seconds.
Returns
SCE_OK on success, 0x800F1326 when not activated, 0x800F1329 when the RTC backup battery has failed, 0x80251002 when the current time cannot be established, or another negative error code.
