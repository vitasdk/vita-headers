Performs the first MLNPSNL authentication phase.

The SceDriverUser wrapper takes four buffers and sets all copy sizes to their maximum values. Keep the returned session data unchanged for the second authentication phase. All pointers must be non-NULL. Both output structures are built in zero-initialized kernel buffers. The requested byte counts are copied back even when authentication reports an error. This function does not use any caller buffer after it returns.

Parameters
[in]request- Phase-one request. Set opt->request_size to exactly 0x20.
[in]secure_tick- Secure tick. Set opt->secure_tick_size to exactly 8.
[out]response- Receives the phase-one response. opt->response_size must be at most 0x80; the system wrapper requests the complete structure.
[in]opt- Copy sizes and session-data destination.
Note
The calling process must be authorized as a system program.
Returns
0 on success; 0x808A0200 when an authentication buffer is NULL; or another negative copy, authorization, size, or authentication error.
