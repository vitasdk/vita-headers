◆ ksceKernelSetGPOMask()

int ksceKernelSetGPOMask ( SceUInt32  clear_mask,
SceUInt32  set_mask 
)

Atomically update the GPO enable mask.

The new mask is (oldMask & ~clear_mask) | set_mask and takes effect on the next GPO write or when GPO state is restored on resume.

Parameters
[in]clear_mask- Bits to clear from the current mask.
[in]set_mask- Bits to set in the current mask.
Returns
0.
