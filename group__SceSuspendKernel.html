◆ ksceKernelSysEventDispatch()

int ksceKernelSysEventDispatch ( SceBool  resume,
SceUInt32  event_id,
void *  event_param,
SceUID *  failed_handler_id 
)

Call registered handlers for a suspend or resume event.

If a handler fails and failed_handler_id is non-NULL, stop calling handlers and write the failing handler's UID to *failed_handler_id. If failed_handler_id is NULL, continue calling handlers after failures and return the last handler's result.

Parameters
[in]resume- Zero while suspending, or one while resuming.
[in]event_id- Event identifier.
[in]event_param- Event data passed to each handler that is called.
[out]failed_handler_id- Optional output for the first failing handler UID.
Returns
The result from the last handler called, or 0 when no handler is registered.
