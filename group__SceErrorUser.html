◆ _sceErrorGetExternalString()

int _sceErrorGetExternalString ( char *  error_string,
int  error_code 
)

Convert an internal error code to its formatted external error code.

Known public errors use PREFIX-number-checkdigit. Unknown errors use E-xxxxxxxx, and known non-public errors use *-xxxxxxxx. Hexadecimal digits are lowercase on FW 3.60. A non-NULL destination receives exactly 16 bytes, including the NUL terminator and zero padding.

Parameters
[out]error_string- Optional external error-code buffer. If non-NULL, it must point to at least 16 bytes.
[in]error_code- Internal error code.
Returns
0 on success, or a user-memory copy error.

Clear the in-memory error history and remove vd0:history/data.bin.

vd0:history/data.bak is not removed immediately. The empty history is written to both files on the next suspend event.

Parameters

◆ _sceErrorHistoryGetError()

int _sceErrorHistoryGetError ( SceUInt32  error_idx,
SceErrorHistoryInfo *  info 
)

Get an error-history entry.

Empty slots are returned as zero-filled records. For a non-NULL output and an invalid index, FW 3.60 also writes a zero-filled record before returning the error.

Parameters
[in]error_idx- Entry index. 0 is the newest entry and 9 is the oldest.
[out]info- The returned error-history entry.
Returns
0 on success, 0x80010016 for a NULL output or an index greater than 9, or a user-memory copy error.

◆ _sceErrorHistoryPostError()

int _sceErrorHistoryPostError ( const SceErrorHistoryPostInfo *  info)

Post an error-history entry.

SceError copies the record before returning. It replaces the system-version fields, conditionally replaces network_status with the registered default, clears reserved2, assigns the RTC timestamp and sequence ID, and generates the external error string. A prior entry with the same internal error code, application code, and first 10 title-ID bytes is removed. The history is not written to storage until a suspend event.

Parameters
[in]info- Error information to post.
Returns
0 on success, 0x80010016 for a NULL record, or a user-memory copy error.
