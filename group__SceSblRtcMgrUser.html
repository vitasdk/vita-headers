◆ sceSblRtcMgrSetCpRtcLogical()

int sceSblRtcMgrSetCpRtcLogical ( int  rtc)

Request a new 32-bit CP logical RTC value.

The calling process must be a system program. FW 3.60 treats rtc as an unsigned 32-bit value and checks that it is from 946652400 through

  1. It does not change the RTC, even when the value is valid.
Parameters
[in]rtc- Requested logical RTC value.
Returns
0x800F1025 for a valid value on FW 3.60.
