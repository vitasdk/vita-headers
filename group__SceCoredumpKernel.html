typedef int(* SceKernelCoredumpStateUpdateCallback) (int task_id, ScePID pid, int progress)

Coredump progress callback.

FW 3.60 reports percentages from 0 through 100, with intermediate updates at multiples of five percentage points. The callback return value is ignored.

Parameters
[in]task_idCoredump task identifier.
[in]pidProcess identifier.
[in]progressCurrent coredump progress.

typedef int(* SceKernelCoredumpStateFinishCallback) (int task_id, ScePID pid, int result, const char *path, SceSize path_len, int is_caf)

Coredump completion callback.

Parameters
[in]task_idCoredump task identifier.
[in]pidProcess identifier.
[in]resultCoredump operation result.
[in]pathPath of the generated coredump.
[in]path_lenLength of path including its terminating NUL.
[in]is_cafNonzero if path identifies a CAF crash report; zero if it identifies a plain PSP2 coredump.

int ksceCoredumpCafSegmentTransform ( SceUID  ctx,
const void *  src,
void *  dst,
SceSize  size 
)

Transforms and authenticates CAF segment data.

HMAC-only mode authenticates src without writing dst. Encryption mode AES-CBC encrypts src to dst and authenticates the ciphertext. Decryption mode authenticates the ciphertext in src before decrypting it to dst.

Parameters
[in]ctxCAF context UID.
[in]srcSource buffer. Must be non-NULL when size is nonzero.
[out]dstDestination buffer. Must be non-NULL when size is nonzero, including in HMAC-only mode where it is not written.
[in]sizeNumber of bytes to process. Must be a multiple of 16 in the AES-CBC modes.
Returns
0 on success, < 0 on error.

◆ ksceCoredumpCreateDump()

int ksceCoredumpCreateDump ( ScePID  pid,

int  app_version,
char *  path,

Creates a coredump for a process and waits for completion.

FW 3.60 selects plaintext PSP2DMP or encrypted CAF output from the coredump configuration and target process. All calls share the same wait and path state, so do not call this function concurrently. Its internal completion callback ignores the worker's coredump result, so a return of 0 means the request completed but does not mean dump generation succeeded.

Parameters
[in]pidProcess identifier.
[in]titleidTitle ID. Must be non-NULL.
[in]titleid_lenNumber of bytes to copy from titleid; maximum 10.
[in]app_nameApplication name. Must be non-NULL.
[in]app_name_lenNumber of bytes to copy from app_name; maximum 0x80.
[in]app_versionDecimal application version; for example, 100 is 01.00.
[out]pathOptional buffer that receives the generated coredump path.
[in]path_sizeSize of path. Must be nonzero when path is non-NULL.
Returns
0 after the request completes, or < 0 on a request, wait, or cleanup error. The worker's dump-generation result is not returned.

Finalizes CAF cryptographic support.

The coredump key stores are securely cleared. Existing context objects are not destroyed; the needed keys are loaded again at the next header or segment initialization.
