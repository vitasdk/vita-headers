◆ ksceCameraIsActive()

int ksceCameraIsActive ( ScePID  pid,
SceUInt32 *  status 
)

Check which active cameras a process owns.

A status bit is set only when the target process has opened and started the corresponding camera and remains its current global owner. An invalid or nonexistent process ID, or an uninitialized Camera driver, is reported as inactive, not as an error.

Parameters
[in]pid- Target process ID.
[out]status- Receives a bitwise OR of SceCameraActiveStatusFlag values. Must not be NULL.
Returns
1 if either camera is active, 0 if neither camera is active, or 0x802E0000 (SCE_CAMERA_ERROR_PARAM) if status is NULL.
