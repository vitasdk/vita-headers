◆ ksceKernelBacktrace()

int ksceKernelBacktrace ( SceUID  thread_id,
SceKernelCallFrame *  call_frame_buffer,
SceSize  num_bytes_buffer,
SceUInt32 *  num_frames,
SceInt32  mode 
)

Get a thread backtrace.

Parameters
[in]thread_idThread ID, or SCE_KERNEL_BACKTRACE_CONTEXT_CURRENT.
[out]call_frame_bufferBuffer that receives call frames, or NULL when num_bytes_buffer is 0.
[in]num_bytes_bufferSize of the call-frame buffer in bytes. A non-NULL buffer must have room for at least one frame.
[out]num_framesReceives the number of frames written to the output buffer. May be NULL.
[in]modeBitwise OR of SceKernelBacktraceMode values.
Returns
On success, 0 with SCE_KERNEL_BACKTRACE_MODE_DONT_EXCEED set; otherwise, the total number of frames in the call stack, including frames that did not fit in the output buffer. Returns < 0 on error.
Note
On FW 3.60 this function requires development mode. Kernel-mode unwinding also requires the corresponding QAF permission.
