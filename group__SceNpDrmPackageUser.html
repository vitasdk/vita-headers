Detailed Description

Exports for User.

Using this library in your project

Include the header file in your project:

#include <psp2/npdrmpackage.h>
npdrmpackage.h


Link the library to the executable:

SceNpDrm_stub


On FW 3.60, every function in this library except sceNpDrmPackageIsGameExist is restricted to system programs with auth ID 0x2800000000000001, 0x280000000000002D, 0x280000000000002E, or 0x2800000000000039.

The started and finished notification functions copy at most 0x40 bytes from the message buffer before returning. You may reuse or free the buffer after the function returns.

◆ _sceNpDrmPackageCheck()

int _sceNpDrmPackageCheck ( const void *  buffer,
SceSize  size,
int  opt,
unsigned int  identifier 
)

Read the header of the PKG and initialize the context.

The caller must be one of the system programs accepted by FW 3.60.

Parameters
[in]buffer- Buffer containing the PKG header
[in]size- Buffer size. A normal check requires at least 0x8000 bytes.
[in]opt- A 32-bit user pointer to a SceNpDrmPackageCheckOpt structure, or 0. The parameter remains an integer for backwards compatibility. The structure contents are ignored on FW 3.60. Any nonzero pointer requests that the context be destroyed.
[in]identifier- Value whose low byte selects one of six contexts. Bit 0x100 creates or uses the context. Bit 0x200 also requests that the context be destroyed and requires a nonzero opt.
Returns
0 on success, < 0 on error

SceSblDmac5HashTransformContext *  context,

)

Update a package hash-transform context.

The caller must be one of the system programs accepted by FW 3.60.

Parameters
[in]buffer- Input data
[in]size- Size of the input data; must be nonzero
[in,out]context- Required hash context. All 0x28 bytes are copied in before the update and copied back afterwards.
[in]identifier- Package identifier and flags. Bit 0x10000 copies the 0x20-byte DMAC5 hash output into context->state. Bit 0x40000000 selects DMAC5 command 3 instead of command 0x13.
Returns
0 on success, < 0 on error
