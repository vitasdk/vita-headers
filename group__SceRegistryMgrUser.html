◆ SceRegMgrSystemParam

enum SceRegMgrSystemParam

System-parameter IDs accepted by the SceRegMgrForGame exports on FW 3.60.

Each ID maps to the registry category and key shown in its comment. The setter functions accept only entries explicitly marked writable; using a known read-only ID returns 0x800D0015.

◆ sceRegMgrSystemParamGetBin()

SceInt32 sceRegMgrSystemParamGetBin ( SceRegMgrSystemParam  id,
void *  buf,
SceSize  buf_size 
)

Gets a system parameter as binary data.

FW 3.60 looks up id in its fixed SceRegMgrSystemParam table and copies exactly min(buf_size, 0x800) bytes to buf on success. The buffer is not used after this function returns. An unknown ID or a NULL buffer returns 0x800D0004.

Parameters
[in]id- System-parameter ID.
[out]buf- Destination buffer.
[in]buf_size- Requested byte count.
Returns
0 on success, or a negative error code.

◆ sceRegMgrSystemParamSetBin()

SceInt32 sceRegMgrSystemParamSetBin ( SceRegMgrSystemParam  id,
const void *  buf,
SceSize  buf_size 
)

Sets a writable system parameter from binary data.

FW 3.60 requires a non-NULL buffer and buf_size no greater than 0x7C0. It copies exactly buf_size bytes to kernel memory before returning and does not use the buffer afterwards. The selected registry key must have binary type. Unknown IDs return 0x800D0004 and known read-only IDs return 0x800D0015.

Parameters
[in]id- Writable system-parameter ID.
[in]buf- Source bytes.
[in]buf_size- Number of bytes to copy and store.
Returns
0 on success, or a negative error code.

◆ sceRegMgrSystemParamSetStr()

SceInt32 sceRegMgrSystemParamSetStr ( SceRegMgrSystemParam  id,
const char *  buf,
SceSize  buf_size 
)

Sets a writable string system parameter.

FW 3.60 requires a non-NULL buffer and buf_size no greater than 0x7C0. It copies exactly buf_size bytes without adding or checking for a NUL terminator. Include the terminator when the selected key requires it. The buffer is not used after this function returns. Unknown IDs return 0x800D0004 and known read-only IDs return 0x800D0015.

Parameters
[in]id- Writable system-parameter ID whose registry key is a string.
[in]buf- Characters to copy.
[in]buf_size- Number of bytes to copy and store.
Returns
0 on success, or a negative error code.
